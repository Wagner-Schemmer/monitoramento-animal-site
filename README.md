# RebanhoVivo — Site do projeto de monitoramento animal

Site estático (HTML + CSS + JS separados, sem build). Abre com Go Live.

```
monitoramento-animal-site/
├── index.html          # todas as seções
├── css/variables.css   # tokens
├── css/components.css  # botões, cards, tabelas
├── css/style.css       # base + layout
├── js/main.js          # reveal + demo do acelerômetro
└── assets/             # imagens (adicionar)
```

## Rodar
Go Live no VSCode ou `python3 -m http.server` na pasta.

## Marca
Nome de trabalho: **RebanhoVivo** (trocar em `index.html` + `<title>` quando decidirem).
